# HarmonyOS Symbol Reference

Source: `name_map_new.json` (version 2.1) from `https://developer.huawei.com/allianceCmsResource/resource/HUAWEI_Developer_VUE/template/resources/hm-symbol/name_map_new.json`

## Usage Rules

- Names from this list are used as `$r('sys.symbol.<name>')` — **no `ohos_` prefix**.
- A small subset also works with `ohos_` prefix (e.g. `ohos_trash`, `ohos_wifi`, `ohos_folder_badge_plus`), but the direct name is preferred.
- Some names that work in the SDK are NOT in this JSON (e.g. `ellipsis_message_1`, `AI`).
- If a symbol fails with "Unknown resource name", it may require a newer API version — the current project targets SDK 5.0.0(12).

## ToolCallCard Icon Mapping

| Tool name contains | Symbol |
|---|---|
| web, browser, fetch, url, search, find, glob, grep | `magnifyingglass` |
| bash, cmd, shell, terminal, tool, exec, run, deploy | `gearshape` |
| edit, write, modify | `pencil_waveform` |
| read, cat | `doc_text` |
| create, new, add, make | `ohos_folder_badge_plus` |
| delete, remove, rm | `ohos_trash` |
| folder, dir, ls | `folder` |
| fallback | `paperclip` |
